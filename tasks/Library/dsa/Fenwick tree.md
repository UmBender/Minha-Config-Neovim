# Fenwick tree

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/fenwick-tree.cpp` and `examples/dsa/fenwick-tree.cpp` (plus variants). Edit those, not this page.

Point add / prefix and range sums over any additive type (BIT), 0-indexed.

Insert with `<leader>rl` → `dsa/fenwick-tree` → normal.

## Variants

Chosen in the second `<leader>rl` menu.

| Variant | Id | Description |
| ------- | -- | ----------- |
| normal | `dsa/fenwick-tree` | Point add / prefix and range sums over any additive type (BIT), 0-indexed. |
| educational | `dsa/fenwick-tree.edu` | Same code and API as the normal Fenwick tree, commented: how and why it works. |
| [[#Fenwick tree (range add, range sum)]] | `dsa/fenwick-tree.range` | Range add and range sum with two plain Fenwick arrays, 0-indexed. |

## Usage

```cpp
Fenwick<long long> fw(n);   Fenwick<long long> fw(a);   // zeros / from a vector in O(n)
fw.add(i, x);  fw.set(i, x);  fw.get(i);
fw.sum(r)      sum of [0, r)        fw.sum(l, r)   sum of [l, r)
fw.lowerBound(s)  smallest r with sum(r) >= s (all values >= 0); n + 1 if none, 0 if s <= 0
T defaults to long long: Fenwick fw(n).  Range add + range sum: the range variant.
```

## Complexity

O(log n) per operation, O(n) build.

## Example

n numbers and q queries: "1 i x" adds x to a[i], "2 l r" prints the sum of a[l..r),
"3 s" prints the shortest prefix length with sum >= s (all a[i] >= 0; n + 1 if none).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/fenwick-tree.cpp"  // in a solution: <leader>rl -> dsa/fenwick-tree -> normal

int main() {
    int n, q;
    cin >> n >> q;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;
    Fenwick fw(a);  // T = long long deduced from a; Fenwick fw(n) starts with zeros
    while (q--) {
        int type;
        cin >> type;
        if (type == 1) {
            int i;
            ll x;
            cin >> i >> x;
            fw.add(i, x);
        } else if (type == 2) {
            int l, r;
            cin >> l >> r;
            cout << fw.sum(l, r) << '\n';
        } else {
            ll s;
            cin >> s;
            cout << fw.lowerBound(s) << '\n';
        }
    }
}
```

## Fenwick tree (range add, range sum)

Range add and range sum with two plain Fenwick arrays, 0-indexed.

Insert with `<leader>rl` → `dsa/fenwick-tree` → range.

### Usage

```cpp
RangeFenwick<long long> rf(n);  RangeFenwick<long long> rf(a);   // zeros / from a vector
rf.add(l, r, x)    add x to a[l, r)
rf.sum(r)          sum of [0, r)        rf.sum(l, r)   sum of [l, r)
rf.get(i);  rf.set(i, x);
```

### Complexity

O(log n) per operation, O(n log n) build from a vector.

### Example

n numbers and q queries: "1 l r x" adds x to a[l..r) (range variant), "2 i x" adds x
to a[i] only, "3 l r" prints the sum of a[l..r).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/fenwick-tree.range.cpp"  // in a solution: <leader>rl -> dsa/fenwick-tree -> range

int main() {
    int n, q;
    cin >> n >> q;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;

    RangeFenwick rf(a);

    while (q--) {
        int type;
        cin >> type;
        if (type == 1) {
            int l, r;
            ll x;
            cin >> l >> r >> x;
            rf.add(l, r, x);
        } else if (type == 2) {
            int i;
            ll x;
            cin >> i >> x;
            rf.add(i, i + 1, x);
        } else {
            int l, r;
            cin >> l >> r;
            cout << rf.sum(l, r) << '\n';
        }
    }
}
```
