# Cartesian tree

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/cartesian-tree.cpp` and `examples/dsa/cartesian-tree.cpp`. Edit those, not this page.

Parent of each index in the Cartesian tree defined by a comparator; root's parent is -1.

Insert with `<leader>rl` → `dsa/cartesian-tree`.

## Usage

```cpp
auto par = cartesianTree(n, [&](int i, int j) { return a[i] < a[j]; });   // min at the root
above(i, j) (called with i > j): true if i must be an ancestor of j.
a[i] < a[j]  -> min-heap, ties: leftmost is the ancestor
a[i] <= a[j] -> min-heap, ties: rightmost is the ancestor
a[i] > a[j]  -> max-heap
In-order traversal of the tree is 0, 1, ..., n - 1.
Presets (a: vector<T>; ties: the leftmost one is the ancestor):
vector<int> par = minCartesianTree(a);   // min at the root
vector<int> par = maxCartesianTree(a);   // max at the root
```

## Complexity

O(n).

## Example

histogram with n bars of heights h[i] (width 1). Print the parent of each bar in the
min and in the max Cartesian tree, then the area of the largest rectangle (each bar is the
minimum of the range spanned by its subtree in the min tree).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/cartesian-tree.cpp"  // in a solution: <leader>rl -> dsa/cartesian-tree

int main() {
    int n;
    cin >> n;
    vector<ll> h(n);
    for (auto &x : h) cin >> x;

    vector<int> par = minCartesianTree(h);  // preset: parents, min at the root, -1 for the root
    for (int p : par) cout << p << ' ';
    cout << '\n';
    for (int p : maxCartesianTree(h)) cout << p << ' ';
    cout << '\n';
    // general form, e.g. ties to the right: cartesianTree(n, [&](int i, int j) { return h[i] <= h[j]; })

    vector<vector<int>> ch(n);
    int root = -1;
    for (int i = 0; i < n; i++) {
        if (par[i] == -1) root = i;
        else ch[par[i]].push_back(i);
    }
    vector<int> L(n), R(n);  // subtree of v = indices [L[v], R[v])
    ll best = 0;
    auto dfs = [&](auto self, int v) -> void {
        L[v] = v, R[v] = v + 1;
        for (int c : ch[v]) self(self, c), L[v] = min(L[v], L[c]), R[v] = max(R[v], R[c]);
        best = max(best, h[v] * (R[v] - L[v]));
    };
    dfs(dfs, root);
    cout << best << '\n';
}
```

Input:

```
7
2 1 4 5 1 3 3
```

Output:

```
1 -1 4 2 1 4 5
2 0 3 -1 5 3 5
8
```
