# Cartesian tree

> `lib/dsa/cartesian-tree.cpp` and `examples/dsa/cartesian-tree.cpp`. Edit those, not this page.

Parent of each index in the Cartesian tree defined by a comparator; root's parent is -1.

Insert with `<leader>rl` → `dsa/cartesian-tree`.

## Usage

```cpp
auto par = cartesianTree(n, [&](int i, int j) { return a[i] < a[j]; });   // min at the root
above(i, j) (called with i > j): true if i must be an ancestor of j.
a[i] < a[j]  -> min-heap, ties: leftmost is the ancestor
a[i] <= a[j] -> min-heap, ties: rightmost is the ancestor
a[i] > a[j]  -> max-heap
In-order traversal of the tree is 0, 1, ..., n - 1.
```

## Complexity

O(n).
