# Zeta and Mobius transforms

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/zeta.cpp` and `examples/dsa/zeta.cpp` (plus variants). Edit those, not this page.

Sums over subsets/supersets (bitmask) and over divisors/multiples, plus their inverses.

Insert with `<leader>rl` → `dsa/zeta` → normal.

## Variants

Chosen in the second `<leader>rl` menu.

| Variant | Id | Description |
| ------- | -- | ----------- |
| normal | `dsa/zeta` | Sums over subsets/supersets (bitmask) and over divisors/multiples, plus their inverses. |
| [[#GCD convolution]] | `dsa/zeta.gcd-conv` | c[k] = sum over gcd(i, j) == k of a[i] b[j] on indices 1..n, exact or modulo mod. |
| [[#LCM convolution]] | `dsa/zeta.lcm-conv` | c[k] = sum over lcm(i, j) == k of a[i] b[j] on indices 1..n, exact or modulo mod. |

## Usage

```cpp
All take the vector by value and return the transformed one (any numeric T).
subsetZeta(a)       b[S] = sum of a[T], T subset of S      (a.size() a power of two)
subsetZeta(a, op)   any associative + commutative op, e.g. max:  [](T x, T y) { return max(x, y); }
supersetZeta(a[, op])   b[S] = sum of a[T], T superset of S
subsetMobius / supersetMobius     inverses (for sums)
divisorZeta(a)      b[m] = sum of a[d], d | m        (indices 1..n, a.size() = n + 1, a[0] untouched)
multipleZeta(a)     b[d] = sum of a[m], d | m <= n
divisorMobius / multipleMobius    inverses
gcd convolution by hand: multipleMobius(multipleZeta(a) * multipleZeta(b) pointwise)
Ready-made gcd / lcm convolutions: the gcd-conv, lcm-conv variants in the <leader>rl menu.
```

## Complexity

O(n log n) for masks (n = 2^k), O(n log log n) for divisors.

## Example

given a[1..n] and b[1..n], print c[k] = sum over gcd(i, j) == k of a[i] b[j], then the
same with lcm(i, j) == k (k <= n). Then, for m masks over k bits with weights, print for every
mask S how many of the masks are subsets of S and the largest weight among them (0 if none).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/zeta.cpp"  // in a solution: <leader>rl -> dsa/zeta -> normal

void print(const vector<ll> &c, int from) {
    for (int i = from; i < (int)c.size(); i++) cout << c[i] << " \n"[i + 1 == (int)c.size()];
}

int main() {
    int n;
    cin >> n;
    vector<ll> a(n + 1), b(n + 1);  // indices 1..n
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];
    // gcd convolution: sums over multiples, multiply pointwise, invert (gcd-conv variant: ready-made)
    vector<ll> A = multipleZeta(a), B = multipleZeta(b), C(n + 1);
    for (int i = 0; i <= n; i++) C[i] = A[i] * B[i];
    print(multipleMobius(C), 1);
    // lcm convolution: the same with divisors
    A = divisorZeta(a), B = divisorZeta(b);
    for (int i = 0; i <= n; i++) C[i] = A[i] * B[i];
    print(divisorMobius(C), 1);

    int k, m;
    cin >> k >> m;
    vector<ll> cnt(1 << k), best(1 << k);
    for (int i = 0; i < m; i++) {
        int mask;
        ll w;
        cin >> mask >> w;
        cnt[mask]++, best[mask] = max(best[mask], w);
    }
    print(subsetZeta(cnt), 0);                                             // sum over subsets
    print(subsetZeta(best, [](ll x, ll y) { return max(x, y); }), 0);  // any op: max over subsets
}
```

Input:

```
6
3 1 4 1 5 9
2 6 5 3 5 8
3 5
1 7
3 2
4 5
6 1
5 4
```

Output:

```
358 112 97 3 25 72
6 26 43 23 50 282
0 1 0 2 1 3 2 5
0 7 0 7 5 7 5 7
```

## GCD convolution

c[k] = sum over gcd(i, j) == k of a[i] b[j] on indices 1..n, exact or modulo mod.

Insert with `<leader>rl` → `dsa/zeta` → gcd-conv.

### Usage

```cpp
vector<long long> c = gcdConv(a, b);         // a, b on indices 1..n (index 0 ignored), exact
vector<long long> c = gcdConv(a, b, mod);    // modulo mod (inputs may be negative or unreduced)
c.size() = max(a.size(), b.size()), c[0] = 0
```

### Complexity

O(n log log n).

### Example

given a[1..n] and b[1..n], print c[k] = sum over gcd(i, j) == k of a[i] b[j],
exactly and modulo 7.

```cpp

#include "dsa/zeta.gcd-conv.cpp"  // in a solution: <leader>rl -> dsa/zeta -> gcd-conv

    for (int i = 1; i < (int)c.size(); i++) cout << c[i] << " \n"[i + 1 == (int)c.size()];

    int n;
    cin >> n;
    vector<ll> a(n + 1), b(n + 1);  // indices 1..n
```
