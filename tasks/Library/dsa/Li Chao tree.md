# Li Chao tree

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/li-chao.cpp` and `examples/dsa/li-chao.cpp`. Edit those, not this page.

Min (or max) of lines/segments y = a x + b at integer points, any coordinate range (sparse).

Insert with `<leader>rl` → `dsa/li-chao`.

## Usage

```cpp
LiChao<long long> lc(lo, hi);            // x in [lo, hi), e.g. (-1e9, 1e9 + 1); min by default
LiChao<long long, true> lc(lo, hi);      // max
lc.addLine(a, b);                        // on the whole range
lc.addSegment(a, b, l, r);               // only for x in [l, r)
lc.query(x)                              // best value at x, LiChao<...>::NONE if no line covers x
Watch overflow: |a x + b| must fit in T.
```

## Complexity

O(log C) per line and query, O(log^2 C) per segment, C = hi - lo.
