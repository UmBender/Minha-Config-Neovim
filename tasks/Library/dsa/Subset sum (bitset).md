# Subset sum (bitset)

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/fast-subset-sum.cpp` and `examples/dsa/fast-subset-sum.cpp`. Edit those, not this page.

All reachable subset sums of non-negative weights, with recovery of one subset per sum.

Insert with `<leader>rl` → `dsa/fast-subset-sum`.

## Usage

```cpp
SubsetSum ss(w);           // w: vector<int>, w[i] >= 0
ss.can(s)                  // is s a subset sum?
ss.recover(s)              // indices of one subset with sum s (requires can(s))
```

## Complexity

O(n S / 64) time, O(S) memory, S = sum of weights.
