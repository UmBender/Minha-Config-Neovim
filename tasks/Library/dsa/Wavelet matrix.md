# Wavelet matrix

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/wavelet-matrix.cpp` and `examples/dsa/wavelet-matrix.cpp`. Edit those, not this page.

Static range queries on values: k-th smallest, counts, predecessor/successor, sums, decomposition.

Insert with `<leader>rl` → `dsa/wavelet-matrix`.

## Usage

```cpp
WaveletMatrix<long long> wm(a);          // any ordered T; values are compressed internally
wm.kth(l, r, k)          k-th smallest (0-indexed) in a[l, r)
wm.countLess(l, r, x)    # of a[i] < x in [l, r)        wm.count(l, r, lo, hi)  # with lo <= a[i] < hi
wm.prev(l, r, x)         largest value < x  (optional)  wm.next(l, r, x)  smallest value >= x (optional)
wm.sum(l, r, lo, hi)     sum of a[i] in [l, r) with lo <= a[i] < hi (arithmetic T; integer sums
wrap internally, exact whenever the answer fits in long long)
wm.visit(l, r, lo, hi, f)   calls f(h, s, e) for disjoint ranges [s, e) of level h whose elements
are exactly the a[i], i in [l, r), with lo <= a[i] < hi.
wm.pos[h][i]             position of a[i] in level h (h = wm.lg: original order, h = 0: sorted)
-> keep one Fenwick per level indexed by position to support weight updates in rectangles.
```

## Presets

```cpp
WaveletMatrix wm(a);                     // T deduced from a
DistinctCount dc(a);  dc.query(l, r)     // # of distinct values in a[l, r) (any ordered T)
```

## Complexity

O(n log n) build, O(log n) per query (visit: O(log n) ranges).

## Example

static array a of n numbers and q queries on a[l, r). "1 l r k" prints the k-th smallest
(0-indexed), "2 l r x y" the count of values in [x, y), "3 l r x" the largest value < x
("none" if there is none) and "4 l r" the number of distinct values.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/wavelet-matrix.cpp"  // in a solution: <leader>rl -> dsa/wavelet-matrix

int main() {
    int n, q;
    cin >> n;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;
    cin >> q;

    WaveletMatrix wm(a);  // T deduced from a
    DistinctCount dc(a);  // preset: distinct values in a range

    while (q--) {
        int type, l, r;
        cin >> type >> l >> r;
        if (type == 1) {
            int k;
            cin >> k;
            cout << wm.kth(l, r, k) << '\n';
        } else if (type == 2) {
            ll x, y;
            cin >> x >> y;
            cout << wm.count(l, r, x, y) << '\n';
        } else if (type == 3) {
            ll x;
            cin >> x;
            auto p = wm.prev(l, r, x);
            if (p) cout << *p << '\n';
            else cout << "none\n";
        } else {
            cout << dc.query(l, r) << '\n';
        }
    }
}
```
