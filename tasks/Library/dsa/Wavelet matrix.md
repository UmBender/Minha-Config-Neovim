# Wavelet matrix

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/wavelet-matrix.cpp` and `examples/dsa/wavelet-matrix.cpp` (plus variants). Edit those, not this page.

Static range queries on values: k-th smallest, counts, predecessor/successor, sums, decomposition.

Insert with `<leader>rl` → `dsa/wavelet-matrix` → normal.

## Variants

Chosen in the second `<leader>rl` menu.

| Variant | Id | Description |
| ------- | -- | ----------- |
| normal | `dsa/wavelet-matrix` | Static range queries on values: k-th smallest, counts, predecessor/successor, sums, decomposition. |
| [[#Distinct values in a range]] | `dsa/wavelet-matrix.distinct` | Number of distinct values in a[l, r) of a static array, online (any ordered T). |

## Usage

```cpp
WaveletMatrix<long long> wm(a);          // any ordered T; values are compressed internally
wm.kth(l, r, k)          k-th smallest (0-indexed) in a[l, r)
wm.countLess(l, r, x)    # of a[i] < x in [l, r)        wm.count(l, r, lo, hi)  # with lo <= a[i] < hi
wm.prev(l, r, x)         largest value < x  (optional)  wm.next(l, r, x)  smallest value >= x (optional)
wm.sum(l, r, lo, hi)     sum of a[i] in [l, r) with lo <= a[i] < hi (arithmetic T; integer sums
wrap internally, exact whenever the answer fits in long long)
wm.visit(l, r, lo, hi, f)   calls f(h, s, e) for disjoint ranges [s, e) of level h whose elements
are exactly the a[i], i in [l, r), with lo <= a[i] < hi.
wm.pos[h][i]             position of a[i] in level h (h = wm.lg: original order, h = 0: sorted)
-> keep one Fenwick per level indexed by position to support weight updates in rectangles.
T is deduced from a: WaveletMatrix wm(a).  Distinct values in a range: the distinct variant.
```

## Complexity

O(n log n) build, O(log n) per query (visit: O(log n) ranges).

## Example

static array a of n numbers and q queries on a[l, r). "1 l r k" prints the k-th smallest
(0-indexed), "2 l r x y" the count of values in [x, y), "3 l r x" the largest value < x
("none" if there is none) and "4 l r x" the sum of values < x.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/wavelet-matrix.cpp"  // in a solution: <leader>rl -> dsa/wavelet-matrix -> normal

int main() {
    int n, q;
    cin >> n;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;
    cin >> q;

    WaveletMatrix wm(a);  // T deduced from a

    while (q--) {
        int type, l, r;
        cin >> type >> l >> r;
        if (type == 1) {
            int k;
            cin >> k;
            cout << wm.kth(l, r, k) << '\n';
        } else if (type == 2) {
            ll x, y;
            cin >> x >> y;
            cout << wm.count(l, r, x, y) << '\n';
        } else if (type == 3) {
            ll x;
            cin >> x;
            auto p = wm.prev(l, r, x);
            if (p) cout << *p << '\n';
            else cout << "none\n";
        } else {
            ll x;
            cin >> x;
            cout << wm.sum(l, r, LLONG_MIN, x) << '\n';
        }
    }
}
```

```

5 2 7 2 9 5 1 7
6
1 0 8 3
1 2 6 0
2 1 7 2 6
3 0 4 5
4 0 8 6
4 1 4 8
```

Output:

```

2
3
2
15
11
```

## Distinct values in a range

Number of distinct values in a[l, r) of a static array, online (any ordered T).

Insert with `<leader>rl` → `dsa/wavelet-matrix` → distinct.

### Usage

```cpp
DistinctCount dc(a);   // a: vector<T>, T with operator<
dc.query(l, r)         // # of distinct values in a[l, r) (0 if empty)
```

### Complexity

O(n log n) build and memory, O(log^2 n) per query.

### Example

static array of n words and q queries "l r": print the number of distinct words in
a[l..r).

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "dsa/wavelet-matrix.distinct.cpp"  // in a solution: <leader>rl -> dsa/wavelet-matrix -> distinct

int main() {
    int n, q;
    cin >> n >> q;
    vector<string> a(n);
    for (auto &s : a) cin >> s;
    DistinctCount dc(a);
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << dc.query(l, r) << '\n';
    }
}
```
