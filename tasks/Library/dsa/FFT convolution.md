# FFT convolution

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/fft.cpp` and `examples/dsa/fft.cpp`. Edit those, not this page.

Convolution of real or integer sequences with complex FFT (doubles).

Insert with `<leader>rl` → `dsa/fft`.

## Usage

```cpp
vector<double> c = fftConv(a, b);            // c[k] = sum a[i] b[k - i]
vector<long long> c = fftConvInt(a, b);      // rounded; exact while
(sum a_i^2 + sum b_i^2) * log2(n) < ~9e14  (e.g. values <= 1e4 and n <= 1e5 are fine)
For results modulo a prime use dsa/ntt (nttConv / convMod).
```

## Complexity

O(n log n).
