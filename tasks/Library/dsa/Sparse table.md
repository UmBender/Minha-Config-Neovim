# Sparse table

O(1) range queries for idempotent ops (min, max, gcd, and, or) on a static array.

Insert with `<leader>rl` → `dsa/sparse-table` → normal.

## Usage

```cpp
SparseTable st(a, [](int x, int y) { return min(x, y); });
st.query(l, r)   op over [l, r), requires l < r
op must be idempotent (op(x, x) == x): sums need a prefix-sum array instead.
Plain min / max / gcd tables: the min, max, gcd variants in the <leader>rl menu.
```

## Complexity

O(n log n) build, O(1) query.

## Example

a static array and q queries [l, r): print the range min, max, gcd and bitwise OR.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/sparse-table.cpp"  // in a solution: <leader>rl -> dsa/sparse-table -> normal

int main() {
    int n, q;
    cin >> n >> q;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;

    SparseTable mn(a, [](ll x, ll y) { return min(x, y); });  // op must be idempotent
    SparseTable mx(a, [](ll x, ll y) { return max(x, y); });
    SparseTable g(a, [](ll x, ll y) { return gcd(x, y); });
    SparseTable orT(a, [](ll x, ll y) { return x | y; });

    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << mn.query(l, r) << ' ' << mx.query(l, r) << ' ' << g.query(l, r) << ' ' << orT.query(l, r) << '\n';
    }
}
```

Input:

```
6 3
12 18 6 9 3 24
0 2
1 4
0 6
```

Output:

```
12 18 6 30
6 18 3 31
3 24 3 31
```
