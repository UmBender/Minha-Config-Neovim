# XOR, AND, OR convolution

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/xor-convolution.cpp` and `examples/dsa/xor-convolution.cpp`. Edit those, not this page.

Bitwise convolutions with the fast Walsh-Hadamard / zeta transforms, exact or modulo a prime.

Insert with `<leader>rl` → `dsa/xor-convolution`.

## Usage

```cpp
xorConv(a, b)       c[k] = sum over i ^ j == k of a[i] b[j]   (exact integers)
andConv(a, b)       ... i & j == k;      orConv(a, b)   ... i | j == k
xorConv(a, b, mod)  same modulo a prime mod (mod = 0 means no modulus)
The result has size = next power of two >= max(a.size(), b.size()).
```

## Complexity

O(n log n).
