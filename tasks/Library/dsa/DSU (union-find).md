# DSU (union-find)

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/dsa/dsu.cpp` and `examples/dsa/dsu.cpp`. Edit those, not this page.

Disjoint set union with union by size and path compression; sizes, component count, groups.

Insert with `<leader>rl` → `dsa/dsu`.

## Usage

```cpp
DSU dsu(n);
dsu.unite(a, b)   merges; false if already together
dsu.same(a, b);  dsu.find(x);  dsu.size(x) (size of x's set);  dsu.count() (number of sets)
dsu.groups()      vector of sets (each a vector of elements)
```

## Complexity

O(alpha(n)) amortized per operation.
