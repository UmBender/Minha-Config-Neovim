# Max-add segment tree

Insert with `<leader>rl` → `dsa/max-add-segtree` → normal.

## Usage

```cpp
MaxAddSegtree<long long> seg(n);  MaxAddSegtree<long long> seg(n, init);  MaxAddSegtree<long long> seg(a);
seg.add(l, r, v)    add v to [l, r)
seg.query(l, r)     max of [l, r), requires l < r
seg.get(i)
T defaults to long long: MaxAddSegtree seg(n).  For min: the min variant in the <leader>rl menu.
```

## Complexity

O(log n) per operation.

## Example

n rooms with a[i] people; q events "1 l r v" (v people enter each room of [l, r),
v may be negative) or "2 l r": print the most people in a room of [l, r).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "dsa/max-add-segtree.cpp"  // in a solution: <leader>rl -> dsa/max-add-segtree -> normal

int main() {
    int n, q;
    cin >> n >> q;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;

    MaxAddSegtree mx(a);  // T = long long deduced from a

    while (q--) {
        int type, l, r;
        cin >> type >> l >> r;
        if (type == 1) {
            ll v;
            cin >> v;
            mx.add(l, r, v);
        } else {
            cout << mx.query(l, r) << '\n';
        }
    }
}
```

Input:

```
5 4
3 1 4 1 5
2 0 5
1 1 4 3
2 0 3
2 3 5
```

Output:

```
5
7
5
```
