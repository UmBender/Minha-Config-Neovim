# Hopcroft-Karp

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/graph/hopcroft-karp.cpp` and `examples/graph/hopcroft-karp.cpp`. Edit those, not this page.

Maximum bipartite matching and minimum vertex cover (Konig).

Insert with `<leader>rl` → `graph/hopcroft-karp`.

## Usage

```cpp
HopcroftKarp hk(nl, nr);    // left 0..nl-1, right 0..nr-1
hk.addEdge(u, v);           // u on the left, v on the right
int k = hk.maxMatching();   // hk.matchL[u] / hk.matchR[v], -1 if unmatched
auto [cl, cr] = hk.vertexCover();   // after maxMatching; |cl| + |cr| = k
max independent set = vertices not in the cover
```

## Complexity

O(E sqrt V).

## Example

Workers (left) and jobs (right), each worker can do some jobs. Print the max number of
assignments, who does what, and a minimum set of workers/jobs touching every pair.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "graph/hopcroft-karp.cpp"  // in a solution: <leader>rl -> graph/hopcroft-karp

int main() {
    int nl, nr, m;
    cin >> nl >> nr >> m;
    HopcroftKarp hk(nl, nr);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        hk.addEdge(u, v);
    }
    cout << hk.maxMatching() << '\n';
    for (int u = 0; u < nl; u++) cout << hk.matchL[u] << " \n"[u == nl - 1];
    auto [cl, cr] = hk.vertexCover();
    cout << "workers:";
    for (int u : cl) cout << ' ' << u;
    cout << " jobs:";
    for (int v : cr) cout << ' ' << v;
    cout << '\n';
}
```

Input:

```
3 3 5
0 0
0 1
1 0
2 0
2 2
```

Output:

```
3
1 0 2
workers: 0 1 2 jobs:
```
