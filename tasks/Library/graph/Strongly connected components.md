# Strongly connected components

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/graph/scc.cpp` and `examples/graph/scc.cpp`. Edit those, not this page.

Tarjan SCC (iterative), components numbered in topological order, condensation DAG.

Insert with `<leader>rl` → `graph/scc`.

## Usage

```cpp
SCC s(g);                  // g: vector<vector<int>> adjacency list
s.count; s.comp[v]         // component of v, in [0, count)
every edge u -> v has s.comp[u] <= s.comp[v] (ids are a topological order of the DAG)
s.components()             // vertices of each component
s.condensation(g)          // DAG between components (sorted, no duplicates)
```

## Complexity

O(n + m).

## Example

Count the strongly connected components of a directed graph and print the condensation
DAG in topological order.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "graph/scc.cpp"  // in a solution: <leader>rl -> graph/scc

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
    }
    SCC s(g);
    cout << s.count << '\n';
    auto comps = s.components();
    auto dag = s.condensation(g);
    for (int c = 0; c < s.count; c++) {
        cout << "component " << c << ":";
        for (int v : comps[c]) cout << ' ' << v;
        cout << " ->";
        for (int d : dag[c]) cout << ' ' << d;
        cout << '\n';
    }
}
```

Input:

```
6 7
0 1
1 2
2 0
2 3
3 4
4 3
5 4
```

Output:

```
3
component 0: 5 -> 2
component 1: 0 1 2 -> 2
component 2: 3 4 ->
```
