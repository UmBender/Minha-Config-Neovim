Builds a simple graph with the given degree sequence, or reports that none exists.

Insert with `<leader>rl` → `graph/havel-hakimi`.

## Usage

```cpp
auto res = havelHakimi(d);  // d: vector<int>, d[v] = wanted degree of v
if (res) for (auto [u, v] : *res) ...   // edges of a simple graph; nullopt if d isn't graphical
```

## Complexity

O((n + m) log n).

## Example

Given the wanted degree of each vertex, print a simple graph with those degrees
(edge count, then edges) or NO.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "graph/havel-hakimi.cpp"  // in a solution: <leader>rl -> graph/havel-hakimi

int main() {
    int n;
    cin >> n;
    vector<int> d(n);
    for (auto &x : d) cin >> x;
    auto res = havelHakimi(d);
    if (!res) {
        cout << "NO\n";
        return 0;
    }
    cout << res->size() << '\n';
    for (auto [u, v] : *res) cout << u << ' ' << v << '\n';
    cout << (havelHakimi({3, 3, 1, 1}) ? "YES" : "NO") << '\n';  // not graphical
}
```

Input:

```
5
3 2 2 2 1
```

```

0 2
0 1
4 3
2 1
NO
```
