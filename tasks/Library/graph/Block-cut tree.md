# Block-cut tree

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/graph/block-cut-tree.cpp` and `examples/graph/block-cut-tree.cpp`. Edit those, not this page.

Biconnected components (blocks), cut vertices and the block-cut tree (iterative).

Insert with `<leader>rl` → `graph/block-cut-tree`.

## Usage

```cpp
BlockCutTree b(g);          // g: undirected vector<vector<int>> (both directions), no self-loops
b.isCut[v]                  // articulation point
b.blocks[i]                 // vertices of block i (an isolated vertex is its own block)
b.tree                      // n + blocks.size() nodes: vertex v -- block node n + i if v in block i
```

## Complexity

O(n + m).

## Example

Print the articulation points of an undirected graph and its biconnected components.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "graph/block-cut-tree.cpp"  // in a solution: <leader>rl -> graph/block-cut-tree

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v), g[v].push_back(u);
    }
    BlockCutTree b(g);
    for (int v = 0; v < n; v++)
        if (b.isCut[v]) cout << v << ' ';
    cout << '\n';
    for (auto blk : b.blocks) {
        sort(blk.begin(), blk.end());
        for (int v : blk) cout << v << ' ';
        cout << '\n';
    }
}
```

Input:

```
6 7
0 1
1 2
2 0
1 3
3 4
4 1
4 5
```

Output:

```
1 4
4 5
1 3 4
0 1 2
```
