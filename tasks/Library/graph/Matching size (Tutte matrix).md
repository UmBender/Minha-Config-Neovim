# Matching size (Tutte matrix)

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/graph/matching-size.cpp` and `examples/graph/matching-size.cpp`. Edit those, not this page.

Size of a maximum matching in a general graph, randomized rank of the Tutte matrix.

Insert with `<leader>rl` → `graph/matching-size`.

## Usage

```cpp
int k = matchingSize(n, edges);   // edges: vector<pair<int, int>>, undirected; loops ignored
wrong with probability <= n / 1e9 (it can only underestimate)
```

## Complexity

O(n^3).

## Example

Only the size of a maximum matching is needed (no pairs). Two triangles joined by an
edge, plus an isolated vertex.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "graph/matching-size.cpp"  // in a solution: <leader>rl -> graph/matching-size

int main() {
    int n, m;
    cin >> n >> m;
    vector<pair<int, int>> edges(m);
    for (auto &[u, v] : edges) cin >> u >> v;
    cout << matchingSize(n, edges) << '\n';
}
```

Input:

```
7 7
0 1
1 2
2 0
3 4
4 5
5 3
2 3
```

Output:

```
3
```
