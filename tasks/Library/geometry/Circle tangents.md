# Circle tangents

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/geometry/circle-tangents.cpp` and `examples/geometry/circle-tangents.cpp`. Edit those, not this page.

Common tangent lines of two circles (or tangents from a point), as pairs of touching points.

Insert with `<leader>rl` → `geometry/circle-tangents`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
using P = Point<long double>;
auto t = circleTangents(c1, r1, c2, r2);   // vector<pair<P, P>> {point on circle 1, point on circle 2}
distinct lines only: 4 apart, 3 touching outside, 2 crossing, 1 touching inside, 0 nested or
concentric; the outer tangents come first (both circles on the same side)
tangents from a point q to a circle: circleTangents(c, r, q, 0) -> 2, 1 (q on it) or 0 lines,
.first is the touching point, .second == q
touching circles: the tangent at the contact point has .first == .second
```

## Complexity

O(1).

## Example

a circle (x y r) and a point outside it: print where the tangents from the point touch
the circle; then the number of common tangents of the circle and another one.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "geometry/point.cpp"            // required by geometry/circle-tangents (inserted with it)
#include "geometry/circle-tangents.cpp"  // in a solution: <leader>rl -> geometry/circle-tangents

using P = Point<long double>;

int main() {
    P c, q, c2;
    long double r, r2;
    cin >> c >> r >> q >> c2 >> r2;
    cout << fixed << setprecision(3);
    for (auto [t, _] : circleTangents(c, r, q, 0.0L)) cout << t << '\n';  // a point: radius 0
    cout << circleTangents(c, r, c2, r2).size() << '\n';
}
```

Input:

```
0 0 5
0 10
12 0 3
```

Output:

```
-4.330 2.500
4.330 2.500
4
```
