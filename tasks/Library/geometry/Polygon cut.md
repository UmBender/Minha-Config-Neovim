# Polygon cut

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/geometry/polygon-cut.cpp` and `examples/geometry/polygon-cut.cpp`. Edit those, not this page.

Part of a polygon on the left of the directed line a -> b (Sutherland-Hodgman, one half-plane).

Insert with `<leader>rl` → `geometry/polygon-cut`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
using P = Point<long double>;            // new vertices are built: floating T
vector<P> q = polygonCut(p, a, b);       // p: vertices in order; keeps cross(b - a, x - a) >= 0
the line is infinite; q keeps p's order and orientation; q.size() < 3: nothing (or only a
segment / point on the line) is left
convex p: q is p intersected with the half-plane; the other side: polygonCut(p, b, a)
non-convex p: the pieces stay joined by zero-width edges along the line (areas still add up)
half-plane intersection of a few planes: cut a big box by each line (O(n) per cut)
```

## Complexity

O(n).

## Example

a convex polygon and directed lines: for each line, the area of the part of the polygon
on its left.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "geometry/point.cpp"         // required by geometry/polygon-cut (inserted with it)
#include "geometry/polygon-cut.cpp"   // in a solution: <leader>rl -> geometry/polygon-cut
#include "geometry/polygon-area.cpp"  // for the areas

using P = Point<long double>;

int main() {
    int n, q;
    cin >> n;
    vector<P> p(n);
    for (auto &v : p) cin >> v;
    cin >> q;
    cout << fixed << setprecision(2);
    while (q--) {
        P a, b;
        cin >> a >> b;
        cout << fabsl(polyArea2(polygonCut(p, a, b))) / 2 << '\n';
    }
}
```
