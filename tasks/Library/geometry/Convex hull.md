# Convex hull

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/geometry/convex-hull.cpp` and `examples/geometry/convex-hull.cpp`. Edit those, not this page.

Convex hull as indices into the input, counterclockwise (Andrew's monotone chain).

Insert with `<leader>rl` → `geometry/convex-hull`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
vector<int> h = convexHull(pts);         // pts: vector<Point<T>>, not modified
vector<int> h = convexHull(pts, true);   // also keep the points lying on the hull's edges
counterclockwise from the smallest point (by x, then y); duplicates appear once (lowest index)
all points on a line: its two ends (or every point on it, in order, with `true`); one point: {i}
exact with integer T (|coordinates| <= ~1e9); floating T uses sgn's EPS
```

## Complexity

O(n log n).

## Example

the convex hull of a set of points: its vertices counterclockwise, then also with the
points lying on its edges.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "geometry/point.cpp"        // required by geometry/convex-hull (inserted with it)
#include "geometry/convex-hull.cpp"  // in a solution: <leader>rl -> geometry/convex-hull

using P = Point<long long>;

int main() {
    int n;
    cin >> n;
    vector<P> pts(n);
    for (auto &q : pts) cin >> q;
    for (bool collinear : {false, true}) {
        vector<int> h = convexHull(pts, collinear);  // indices into pts
        cout << h.size() << ':';
        for (int i : h) cout << " (" << pts[i] << ')';
        cout << '\n';
    }
}
```

Input:

```
7
0 0
2 0
1 0
2 2
0 2
1 1
2 2
```

Output:

```
4: (0 0) (2 0) (2 2) (0 2)
5: (0 0) (1 0) (2 0) (2 2) (0 2)
```
