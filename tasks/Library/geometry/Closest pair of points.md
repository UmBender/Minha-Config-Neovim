Indices of two points at the smallest Euclidean distance (sweep line over x).

Insert with `<leader>rl` → `geometry/closest-pair`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
auto [i, j] = closestPair(pts);          // pts: vector<Point<T>>, size >= 2; i < j
distance: (pts[i] - pts[j]).dist(), squared (exact for integers): (pts[i] - pts[j]).dist2()
repeated points are fine (distance 0); integer |coordinates| <= ~1e9
```

## Complexity

O(n log n).

## Example

the squared distance between the two closest points, and which points they are.

#include <bits/stdc++.h>
