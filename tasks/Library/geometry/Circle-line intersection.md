# Circle-line intersection

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/geometry/circle-line.cpp` and `examples/geometry/circle-line.cpp`. Edit those, not this page.

Intersection points (0, 1 or 2) of a circle and the infinite line through two points.

Insert with `<leader>rl` → `geometry/circle-line`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
using P = Point<long double>;
vector<P> v = circleLine(c, r, a, b);   // circle: center c, radius r; line through a != b
v.size(): 0 apart, 1 tangent, 2 crossing (ordered in the direction a -> b)
a segment instead of the line: keep the points with (p - a).dot(p - b) <= 0
tangency is decided by sgn on r^2 - dist^2 (EPS on squared lengths)
```

## Complexity

O(1).

## Example

a circle (center, radius) and lines through two points: print where each line meets it.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "geometry/point.cpp"        // required by geometry/circle-line (inserted with it)
#include "geometry/circle-line.cpp"  // in a solution: <leader>rl -> geometry/circle-line

using P = Point<long double>;

int main() {
    P c, a, b;
    long double r;
    int q;
    cin >> c >> r >> q;
    cout << fixed << setprecision(3);
    while (q--) {
        cin >> a >> b;
        auto v = circleLine(c, r, a, b);
        cout << v.size();
        for (P p : v) cout << " (" << p << ')';
        cout << '\n';
    }
}
```
