# Segment intersection

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/geometry/segment-intersection.cpp` and `examples/geometry/segment-intersection.cpp`. Edit those, not this page.

Do two closed segments touch (segInter) or cross at one interior point (properInter); onSegment.

Insert with `<leader>rl` → `geometry/segment-intersection`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
segInter(a, b, c, d)     // segments ab and cd share at least one point (endpoints, overlaps,
// degenerate segments a == b included)
properInter(a, b, c, d)  // they cross at a single point interior to both
onSegment(p, a, b)       // p lies on the closed segment ab
exact with integer T (|coordinates| <= ~1e9); floating T uses sgn's EPS
the crossing point itself: lineInter (geometry/line-intersection) when properInter holds
```

## Complexity

O(1).

## Example

for each pair of segments, print TOUCH if they share any point (CROSS if they cross at
one point inside both), or NO.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "geometry/point.cpp"                 // required by geometry/segment-intersection
#include "geometry/segment-intersection.cpp"  // in a solution: <leader>rl -> geometry/segment-intersection

using P = Point<long long>;

int main() {
    int q;
    cin >> q;
    while (q--) {
        P a, b, c, d;
        cin >> a >> b >> c >> d;
        cout << (properInter(a, b, c, d) ? "CROSS" : segInter(a, b, c, d) ? "TOUCH" : "NO") << '\n';
    }
}
```
