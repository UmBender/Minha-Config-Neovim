# Polygon area

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/geometry/polygon-area.cpp` and `examples/geometry/polygon-area.cpp`. Edit those, not this page.

Twice the signed area of a polygon (shoelace): positive when counterclockwise.

Insert with `<leader>rl` → `geometry/polygon-area`.
Requires: [[Point]] (inserted automatically).

## Usage

```cpp
T a2 = polyArea2(p);     // p: vector<Point<T>>, vertices in order (not repeated at the end)
area = abs(a2) / 2.0;  a2 > 0: counterclockwise, a2 < 0: clockwise
integer T: exact (twice the area is an integer); lattice points inside (Pick):
(abs(a2) - boundary + 2) / 2, boundary = sum of gcd(|dx|, |dy|) over the edges
```

## Complexity

O(n).

## Example

the area of a polygon (vertices in order, either orientation) and its orientation.

    cin >> n;
