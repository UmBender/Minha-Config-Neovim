# Manacher

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/strings/manacher.cpp` and `examples/strings/manacher.cpp`. Edit those, not this page.

Radius of the longest palindrome at every center, O(1) palindrome checks.

Insert with `<leader>rl` → `strings/manacher`.

## Usage

```cpp
Manacher m(s);           // s: string or any vector<T> (only == is used)
m.odd[i]: palindromes s[i - k + 1, i + k) for k <= odd[i] (length 2 * odd[i] - 1)
m.even[i]: palindromes s[i - k, i + k) for k <= even[i] (length 2 * even[i])
m.isPalindrome(l, r)     // is s[l, r) a palindrome
auto [l, r] = m.longest();   // a longest palindrome s[l, r) (the leftmost one)
```

## Complexity

O(n) build, O(1) per query.

## Example

Print the longest palindromic substring, the number of palindromic substrings
(counted by position), and answer queries "l r": is s[l, r) a palindrome?

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "strings/manacher.cpp"  // in a solution: <leader>rl -> strings/manacher

int main() {
    string s;
    int q;
    cin >> s >> q;
    Manacher m(s);
    auto [l, r] = m.longest();
    long long count = 0;
    for (int i = 0; i < (int)s.size(); i++) count += m.odd[i] + m.even[i];
    cout << s.substr(l, r - l) << '\n' << count << '\n';
    while (q--) {
        int a, b;
        cin >> a >> b;
        cout << (m.isPalindrome(a, b) ? "yes" : "no") << '\n';
    }
}
```

Input:

```
abaaba
3
0 3
1 4
2 4
```

Output:

```
abaaba
11
yes
no
yes
```
