# Runs

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/strings/runs.cpp` and `examples/strings/runs.cpp`. Edit those, not this page.

All maximal repetitions (runs) of a string, with their smallest period.

Insert with `<leader>rl` → `strings/runs`.
Requires: [[Z-function]] (inserted automatically).

## Usage

```cpp
vector<array<int, 3>> r = runs(s);   // {p, l, r}, sorted by (p, l)
s[l, r) has smallest period p, r - l >= 2p, and can't be extended keeping period p.
Every repetition (square, cube, ...) lies inside a run of the same period; there are O(n) runs.
s: string or any vector<T> (only == is used)
```

## Complexity

O(n log n).

## Example

Print every maximal run of s as "period start end" (half-open), then the longest
tandem repeat (a string of the form ww) as a substring.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "strings/z-function.cpp"  // required by strings/runs (the picker inserts it)
#include "strings/runs.cpp"        // in a solution: <leader>rl -> strings/runs

int main() {
    string s;
    cin >> s;
    int bl = 0, blen = 0;
    for (auto [p, l, r] : runs(s)) {
        cout << p << ' ' << l << ' ' << r << '\n';
        int len = (r - l) / (2 * p) * 2 * p;  // longest even power of the period inside the run
        if (len > blen) bl = l, blen = len;
    }
    cout << s.substr(bl, blen) << '\n';
}
```

Input:

```
aabaabab
```

Output:

```
1 0 2
1 3 5
2 4 8
3 0 7
aabaab
```
