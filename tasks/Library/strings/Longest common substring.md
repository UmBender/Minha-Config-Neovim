## Usage

```cpp
auto [i, j, len] = longestCommonSubstring(a, b);   // a.substr(i, len) == b.substr(j, len)
longestCommonSubstring<10, '0'>(a, b)               // alphabet as in strings/suffix-automaton
len == 0 (and i == j == 0) when there is no common character
```
