# LCP array

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/strings/lcp.cpp` and `examples/strings/lcp.cpp`. Edit those, not this page.

Longest common prefix of adjacent suffixes in the suffix array (Kasai).

Insert with `<leader>rl` → `strings/lcp`.

## Usage

```cpp
vector<int> lcp = lcpArray(s, sa);   // sa from strings/suffix-array
lcp[0] = 0, lcp[i] = lcp(s[sa[i - 1]..], s[sa[i]..]) for i >= 1
lcp of any two suffixes: min of lcp over (rank[i], rank[j]], e.g. with dsa/sparse-table
distinct substrings: n(n + 1) / 2 - sum(lcp)
```

## Complexity

O(n).

## Example

Count the distinct non-empty substrings of s, and find the longest substring that
occurs at least twice.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "strings/suffix-array.cpp"  // in a solution: <leader>rl -> strings/suffix-array
#include "strings/lcp.cpp"           // in a solution: <leader>rl -> strings/lcp

int main() {
    string s;
    cin >> s;
    long long n = (long long)s.size(), distinct = n * (n + 1) / 2;
    vector<int> sa = suffixArray(s), lcp = lcpArray(s, sa);
    int best = 0;
    for (int i = 1; i < n; i++) {
        distinct -= lcp[i];  // prefixes shared with the previous suffix were already counted
        if (lcp[i] > lcp[best]) best = i;
    }
    cout << distinct << '\n' << s.substr(sa[best], lcp[best]) << '\n';
}
```

Input:

```
banana
```

Output:

```
15
ana
```
