# Continued fractions and Pell

> [!info] Generated by `tests/run.py --write-docs` from
> `pylib/nt/cont-frac.py` and `examples/py/nt/cont-frac.py`. Edit those, not this page.

Periodic continued fraction of sqrt(n), convergents, Pell equation x^2 - D y^2 = 1.

Insert with `<leader>rl` in a Python buffer → `nt/cont-frac`.

## Usage

```python
a0, period = sqrt_cf(23)          (4, [1, 3, 1, 8]); perfect squares give (r, [])
for p, q in convergents([1, 2, 2, 2]): ...   p/q of each prefix: 1/1, 3/2, 7/5, 17/12
x, y = pell(D)                    minimal solution, None if D is a square
sols = pell_solutions(D); next(sols)   all solutions in increasing order
```

## Complexity

sqrt_cf O(period) = O(sqrt n log n); pell O(period) big-int steps.

## Example

Project Euler 66: the D <= 1000 whose minimal Pell solution has the largest x; and the
numerator of the 10th convergent of e = [2; 1, 2, 1, 1, 4, 1, 1, 6, ...] (PE 65 asks for the 100th).

```python
from libtest import include
include("nt/cont-frac")

print(max((pell(D)[0], D) for D in range(2, 1001) if pell(D))[1])
e = [2] + [x for k in range(1, 40) for x in (1, 2 * k, 1)]
*_, (p, q) = convergents(e[:10])
print(p)
```

Output:

```
661
1457
```
