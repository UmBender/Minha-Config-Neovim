# Prime counting

> [!info] Generated by `tests/run.py --write-docs` from
> `pylib/nt/prime-count.py` and `examples/py/nt/prime-count.py`. Edit those, not this page.

pi(n) and the sum of primes <= n without sieving to n (Lucy_Hedgehog).

Insert with `<leader>rl` in a Python buffer → `nt/prime-count`.

## Usage

```python
prime_pi(10**11)       number of primes <= n
prime_sum(2 * 10**6)   sum of primes <= n
```

## Complexity

O(n^(3/4)) time, O(sqrt n) memory (n = 1e11 takes a few seconds in CPython).

## Example

Project Euler 10: the sum of the primes below two million; and pi(10^10).

```python
from libtest import include
include("nt/prime-count")

print(prime_sum(2 * 10**6))
print(prime_pi(10**10))
```

Output:

```

455052511
```
