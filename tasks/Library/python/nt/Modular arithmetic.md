# Modular arithmetic

> [!info] Generated by `tests/run.py --write-docs` from
> `pylib/nt/modular.py` and `examples/py/nt/modular.py`. Edit those, not this page.

Extended gcd, modular inverse, CRT for any moduli, binomials mod a prime.

Insert with `<leader>rl` in a Python buffer → `nt/modular`.

## Usage

```python
g, x, y = ext_gcd(a, b)     a*x + b*y == g == gcd(a, b)
inv_mod(a, m)               inverse in [0, m), None if gcd(a, m) != 1
crt(rs, ms)                 (r, lcm) with x == r (mod lcm) for all x % m_i == r_i, None if inconsistent
B = Binom(n, mod)           factorials up to n, mod a prime > n
B.C(n, k), B.P(n, k), B.fact[i], B.inv_fact[i], B.inv(i)    (C/P are 0 outside 0 <= k <= n)
Builtins: pow(a, -1, m), pow(b, e, m), math.comb, math.lcm.
```

## Complexity

ext_gcd / inv_mod O(log m); crt O(k log); Binom O(n) build, O(1) per query.

## Example

For each query (n, k) print C(n, k) mod 10^9 + 7; then solve x = 2 (mod 3), x = 3 (mod 5),
x = 2 (mod 7) and the inverse of 3 mod 10.

```python
from libtest import include
include("nt/modular")

MOD = 10**9 + 7
B = Binom(10**5, MOD)
q = int(input())
for _ in range(q):
    n, k = map(int, input().split())
    print(B.C(n, k))
print(*crt([2, 3, 2], [3, 5, 7]))
print(inv_mod(3, 10))
```

Input:

```
3
5 2
100000 50000
3 5
```

Output:

```
10
149033233
0
23 105
7
```
