# Primes and factorization

> [!info] Generated by `tests/run.py --write-docs` from
> `pylib/nt/primes.py` and `examples/py/nt/primes.py`. Edit those, not this page.

Sieve, smallest prime factors, deterministic Miller-Rabin and Pollard rho factorization.

Insert with `<leader>rl` in a Python buffer → `nt/primes`.

## Usage

```python
s = sieve(n)            bytearray, s[i] == 1 iff i is prime (0 <= i <= n)
ps = primes_upto(n)     [2, 3, 5, ...]
spf = spf_sieve(n)      smallest prime factor of 2..n (spf[0] = 0, spf[1] = 1)
is_prime(n)             any int; deterministic below 3.3e24, probabilistic above
factor(n)               Counter {p: e}, e.g. factor(12) == {2: 2, 3: 1}; factor(1) == {}
```

## Complexity

sieve O(n log log n); is_prime O(log^3 n); factor O(n^(1/4)) expected.

## Example

Project Euler 3 and 7: the largest prime factor of 600851475143 and the 10001st prime;
also whether 2^61 - 1 is prime.

```python
from libtest import include
include("nt/primes")

print(max(factor(600851475143)))
print(primes_upto(200000)[10000])
print(is_prime(2**61 - 1))
```

Output:

```
6857
104743
True
```
