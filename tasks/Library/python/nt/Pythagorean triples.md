# Pythagorean triples

> [!info] Generated by `tests/run.py --write-docs` from
> `pylib/nt/pythagorean.py` and `examples/py/nt/pythagorean.py`. Edit those, not this page.

Primitive and all Pythagorean triples (a < b < c) up to a bound on c or on the perimeter.

Insert with `<leader>rl` in a Python buffer → `nt/pythagorean`.

## Usage

```python
for a, b, c in primitive_triples(limit): ...            c <= limit, gcd(a, b) == 1
for a, b, c in triples(limit, key="perimeter"): ...     all triples with a + b + c <= limit
```

## Complexity

O(number of triples) after an O(limit^(1/2)) x O(limit^(1/2)) scan of (m, n).

## Example

Project Euler 39: the perimeter p <= 1000 with the most right triangles with integer sides.

```python
from libtest import include
include("nt/pythagorean")
from collections import Counter

ways = Counter(a + b + c for a, b, c in triples(1000, "perimeter"))
print(ways.most_common(1)[0][0])
```

Output:

```
840
```
