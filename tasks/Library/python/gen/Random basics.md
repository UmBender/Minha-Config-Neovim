# Random basics

> [!info] Generated by `tests/run.py --write-docs` from
> `pylib/gen/rand.py` and `examples/py/gen/rand.py`. Edit those, not this page.

Random arrays, distinct values, permutations, strings, partitions, subsets; edge list printing.

Insert with `<leader>rl` in a Python buffer → `gen/rand`.

## Usage

```python
rand_array(n, lo, hi)          n values in [lo, hi]
rand_distinct(n, lo, hi)       n distinct values in [lo, hi] (any range size)
rand_perm(n, start=0)          permutation of start..start+n-1
rand_string(n, alphabet="ab")
rand_partition(total, k, min_part=0)   k parts >= min_part summing to total (e.g. sum of n over tests)
rand_subset(items, k=None)     random subset (each item w.p. 1/2, or exactly k), original order
fmt(a) -> "1 2 3";  fmt_edges(edges, base=1) -> "u v [w]" lines, vertices shifted by base
All use the global `random`, so random.seed(seed) makes a test reproducible.
```

## Complexity

O(output size).

## Example

Generator for "t tests, each an array of n values in [1, 10^9]; the sum of n over all tests is
exactly 20". Print the test count and the size of each test (the arrays themselves vary with the seed).

```python
from libtest import include
include("gen/rand")
import random

random.seed(1)
t = 3
sizes = rand_partition(20, t, min_part=1)  # every test has n >= 1
tests = [rand_array(n, 1, 10**9) for n in sizes]
print(t)
print(sum(len(a) for a in tests), all(1 <= x <= 10**9 for a in tests for x in a))
# in a real generator:
# print(t)
# for a in tests:
#     print(len(a))
#     print(fmt(a))
```

Output:

```

20 True
```
