# Extended Euclid

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/egcd.cpp` and `examples/math/egcd.cpp`. Edit those, not this page.

gcd(a, b) with x, y such that ax + by = gcd, and the modular inverse for any modulus.

Insert with `<leader>rl` → `math/egcd`.

## Usage

```cpp
long long x, y, g = egcd(a, b, x, y);   // a, b >= 0: a*x + b*y = g, |x| <= b/g, |y| <= a/g
invMod(a, m)                            // a^-1 mod m in [0, m), -1 if gcd(a, m) != 1 (any a, m >= 1)
```

## Complexity

O(log min(a, b)).

## Example

for each query a b c (a, b >= 1) print integers x y with a*x + b*y = c and the smallest
x >= 0, or -1 if there is none; then the inverse of a modulo b (-1 if it doesn't exist).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/egcd.cpp"  // in a solution: <leader>rl -> math/egcd

int main() {
    int q;
    cin >> q;
    while (q--) {
        ll a, b, c, x, y;
        cin >> a >> b >> c;
        ll g = egcd(a, b, x, y);
        if (c % g) {
            cout << -1;
        } else {
            ll step = b / g;  // solutions: x + t * b/g, y - t * a/g
            x = ((__int128)x * (c / g) % step + step) % step;
            y = (c - a * x) / b;
            cout << x << ' ' << y;
        }
        cout << ' ' << invMod(a, b) << '\n';
    }
}
```

```
3

4 6 7

```

-1 -1
