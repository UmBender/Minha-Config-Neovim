# Primality test

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/primality.cpp` and `examples/math/primality.cpp`. Edit those, not this page.

Deterministic Miller-Rabin for every 64-bit integer, plus 64-bit modular helpers.

Insert with `<leader>rl` → `math/primality`.

## Usage

```cpp
isPrime(n)               // unsigned 64-bit n; 0 and 1 are not prime
mulMod64(a, b, m)        // a * b mod m without overflow (__int128), any m < 2^64
powMod64(b, e, m)        // b^e mod m
```

## Complexity

O(log n) multiplications (7 bases).

## Example

for each n (0 <= n < 2^64) print whether it is prime.

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "math/primality.cpp"  // in a solution: <leader>rl -> math/primality

int main() {
    int q;
    cin >> q;
    while (q--) {
        unsigned long long n;
        cin >> n;
        cout << (isPrime(n) ? "Yes" : "No") << '\n';
    }
}
```
