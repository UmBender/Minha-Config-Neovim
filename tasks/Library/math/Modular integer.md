# Modular integer

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/modint.cpp` and `examples/math/modint.cpp` (plus variants). Edit those, not this page.

Integer modulo m with + - * / pow inv; static modulus, or dynamic (set at runtime).

Insert with `<leader>rl` → `math/modint` → normal.

## Variants

Chosen in the second `<leader>rl` menu.

| Variant | Id | Description |
| ------- | -- | ----------- |
| normal | `math/modint` | Integer modulo m with + - * / pow inv; static modulus, or dynamic (set at runtime). |
| [[#Binomials modulo a prime]] | `math/modint.comb` | Inverses of 1..n in O(n), factorials and inverse factorials for C(n, k), P(n, k) with ModInt. |

## Usage

```cpp
using Mint = ModInt<998244353>;           // static modulus (or ModInt<1000000007>), 1 <= M < 2^31
Mint a = -5, b = 1LL << 40;               // any integer type and sign, reduced into [0, mod)
a + b; a - b; a * b; a / b; -a; a += 3; 2 * a; a == b; a.pow(e); a.inv(); a.val(); cin >> a; cout << a;
using DMint = ModInt<0>; DMint::setMod(m);   // dynamic modulus 1 <= m < 2^31 (998244353 until set);
// ModInt<-1>, ModInt<-2>, ... are independent ones
// inv() and / work for any modulus when gcd(val, mod) = 1, else inv() is 0; pow(-e) = inv().pow(e)
```

## Complexity

O(1) per + - * (one 64-bit %), O(log mod) per inv and /, O(log e) per pow.

## Example

first line: a modulus m (1 <= m < 2^31, not necessarily prime). Then q queries "a b":
print (a + b) mod 998244353, (a * b) mod 1e9+7, and a / b mod m (or -1 if b has no inverse mod m).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/modint.cpp"  // in a solution: <leader>rl -> math/modint

using M1 = ModInt<998244353>;   // static moduli
using M2 = ModInt<1000000007>;
using DM = ModInt<0>;           // modulus read from the input

int main() {
    int m, q;
    cin >> m >> q;
    DM::setMod(m);
    while (q--) {
        ll a, b;
        cin >> a >> b;
        DM d = b;
        cout << M1(a) + b << ' ' << M2(a) * b << ' ';
        if (d.inv() * d == 1) cout << DM(a) / d << '\n';
        else cout << -1 << '\n';
    }
}
```

Input:

```
10
3
3 7
-1 4
1000000000000 9
```

Output:

```
10 21 9
3 1000000003 -1
757402656 999937007 0
```

## Binomials modulo a prime

Inverses of 1..n in O(n), factorials and inverse factorials for C(n, k), P(n, k) with ModInt.

Insert with `<leader>rl` → `math/modint` → comb.
Requires: [[Modular integer]] (inserted automatically).

### Usage

```cpp
Comb<Mint> cb(n);          // tables up to n (optional: they grow on demand); prime mod > n
cb.C(n, k); cb.P(n, k);    // binomial, arrangements; 0 if n < 0, k < 0 or k > n
cb.fact(i); cb.ifact(i); cb.inv(i);   // i!, 1 / i!, 1 / i (i >= 1)
// dynamic modulus: build the Comb after setMod (the tables belong to one modulus)
```

### Complexity

O(n) to build up to n, O(1) per query.

### Example

number of lattice paths from (0, 0) to (x, y) with unit steps right/up, modulo 1e9+7
(C(x + y, x)), and the number of ways to seat k of n people in a row (P(n, k)).

```cpp
#include <bits/stdc++.h>
using namespace std;

#include "math/modint.cpp"       // in a solution: <leader>rl -> math/modint -> comb
#include "math/modint.comb.cpp"  // (inserts math/modint too)

using Mint = ModInt<1000000007>;

int main() {
    Comb<Mint> cb;  // grows on demand
    int q;
    cin >> q;
    while (q--) {
        int x, y, n, k;
        cin >> x >> y >> n >> k;
        cout << cb.C(x + y, x) << ' ' << cb.P(n, k) << '\n';
    }
}
```

```
2 2 5 2
3 1 10 0
100000 100000 4 5
```
