# Lagrange interpolation

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/lagrangian-interpolation.cpp` and `examples/math/lagrangian-interpolation.cpp`. Edit those, not this page.

Value at x of the polynomial of degree < n through n points modulo a prime; O(n) for nodes 0..n-1.

Insert with `<leader>rl` → `math/lagrangian-interpolation`.
Requires: [[Modular power]] (inserted automatically).

## Usage

```cpp
lagrange(xs, ys, x, mod)    // distinct nodes xs (mod p), of any sign
lagrange(ys, x, mod)        // nodes 0, 1, ..., n-1 (ys[i] = P(i)), n <= mod
// prime mod < 2^31 (998244353 by default), x any long long (e.g. 1e18)
```

## Complexity

O(n^2 + n log mod); nodes 0..n-1: O(n + log mod).

## Example

print 1^k + 2^k + ... + n^k mod 1e9+7 for huge n (a polynomial of degree k + 1 in n,
interpolated from its values at 0..k+1); then the parabola through (1, 1), (-2, 4), (5, 25) at x = 7.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/powm.cpp"                      // required by math/lagrangian-interpolation (the picker inserts it)
#include "math/lagrangian-interpolation.cpp"  // in a solution: <leader>rl -> math/lagrangian-interpolation

int main() {
    const ll P = 1000000007;
    int q;
    cin >> q;
    while (q--) {
        ll n, k;
        cin >> n >> k;
        vector<ll> ys(k + 2, 0);  // ys[x] = sum_{i <= x} i^k
        for (int x = 1; x < k + 2; x++) ys[x] = (ys[x - 1] + powMod(x, k, P)) % P;
        cout << lagrange(ys, n, P) << '\n';
    }
    cout << lagrange({1, -2, 5}, {1, 4, 25}, 7, P) << '\n';
}
```
