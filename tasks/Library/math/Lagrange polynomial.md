# Lagrange polynomial

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/lagrangian-polynomial.cpp` and `examples/math/lagrangian-polynomial.cpp`. Edit those, not this page.

Coefficients of the polynomial of degree < n through n points, modulo a prime.

Insert with `<leader>rl` → `math/lagrangian-polynomial`.
Requires: [[Modular power]] (inserted automatically).

## Usage

```cpp
vector<long long> c = lagrangePoly(xs, ys, mod);   // P(x) = c[0] + c[1] x + ... + c[n-1] x^(n-1)
// distinct nodes xs (mod p) of any sign; prime mod < 2^31 (998244353 by default)
```

## Complexity

O(n^2 + n log mod).

## Example

print the coefficients (constant term first) of the polynomial of degree < n through the n
points (x_i, y_i), modulo 998244353.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/powm.cpp"                     // required by math/lagrangian-polynomial (the picker inserts it)
#include "math/lagrangian-polynomial.cpp"   // in a solution: <leader>rl -> math/lagrangian-polynomial

int main() {
    int n;
    cin >> n;
    vector<ll> xs(n), ys(n);
    for (auto &x : xs) cin >> x;
    for (auto &y : ys) cin >> y;
    auto c = lagrangePoly(xs, ys);
    for (int i = 0; i < n; i++) cout << c[i] << " \n"[i + 1 == n];
}
```

Input:

```
3
0 1 2
1 3 7
```

Output:
