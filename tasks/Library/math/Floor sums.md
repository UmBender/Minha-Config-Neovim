# Floor sums

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/floor-sum.cpp` and `examples/math/floor-sum.cpp`. Edit those, not this page.

Sums of floor((a*i + b) / m), i * floor(...) and floor(...)^2 over 0 <= i < n, any sign of a, b.

Insert with `<leader>rl` → `math/floor-sum`.

## Usage

```cpp
floorSum(n, m, a, b)                       // sum_{0 <= i < n} floor((a*i + b) / m)        (__int128)
floorSumI(n, m, a, b)                      // sum i * floor((a*i + b) / m)
floorSumSq(n, m, a, b)                     // sum floor((a*i + b) / m)^2
auto [f, g, h] = floorSums(n, m, a, b);    // the three at once
// n >= 0, m >= 1; results (and terms of their size) must fit in __int128
```

## Complexity

O(log m).

## Example

for each query n m a b print sum_{0 <= i < n} floor((a*i + b) / m), then the same sum
weighted by i and of the squares (the last query has a negative slope).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/floor-sum.cpp"  // in a solution: <leader>rl -> math/floor-sum

string str(__int128 x) {  // cout can't print __int128
    if (x < 0) return "-" + str(-x);
    return (x >= 10 ? str(x / 10) : "") + char('0' + x % 10);
}

int main() {
    int q;
    cin >> q;
    while (q--) {
        ll n, m, a, b;
        cin >> n >> m >> a >> b;
        auto s = floorSums(n, m, a, b);  // {floorSum, floorSumI, floorSumSq}
        cout << str(floorSum(n, m, a, b)) << ' ' << str(s[1]) << ' ' << str(s[2]) << '\n';
    }
}
```
