# Modular square root

Smallest x with x^2 = a (mod p) for a prime p (Tonelli-Shanks), or -1 if a is not a square.

Insert with `<leader>rl` → `math/mod-sqrt`.
Requires: [[Modular power]] (inserted automatically).

## Usage

```cpp
sqrtMod(a, p)    // prime p < 2^31 (998244353 by default), any a (reduced first); the other root is p - x
```

## Complexity

O(log^2 p) multiplications.
