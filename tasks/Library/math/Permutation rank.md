# Permutation rank

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/perm-int.cpp` and `examples/math/perm-int.cpp`. Edit those, not this page.

Lexicographic rank of a permutation of 0..n-1 among all n! permutations, and back.

Insert with `<leader>rl` → `math/perm-int`.

## Usage

```cpp
perm2int({2, 1, 0})    // 5
int2perm(3, 5)         // {2, 1, 0}
// n <= 20 (20! - 1 fits in a long long)
```

## Complexity

O(n^2).

## Example

given a permutation of 1..n, print its 1-based position in lexicographic order and the
permutation k positions after it (wrapping around).

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/perm-int.cpp"  // in a solution: <leader>rl -> math/perm-int

int main() {
    int n;
    ll k, total = 1;
    cin >> n;
    vector<int> p(n);
    for (auto &x : p) cin >> x, x--;  // 0-based values
    cin >> k;
    for (int i = 2; i <= n; i++) total *= i;
    ll r = perm2int(p);
    cout << r + 1 << '\n';
    auto q = int2perm(n, (r + k) % total);
    for (int i = 0; i < n; i++) cout << q[i] + 1 << " \n"[i + 1 == n];
}
```

Input:

```
4
3 1 4 2
12
```

Output:

```
14
1 2 4 3
```
