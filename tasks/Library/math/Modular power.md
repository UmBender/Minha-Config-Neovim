# Modular power

> [!info] Generated by `tests/run.py --write-docs` from
> `lib/math/powm.cpp` and `examples/math/powm.cpp`. Edit those, not this page.

b^e mod m by binary exponentiation; inverse modulo a prime as powMod(a, p - 2, p).

Insert with `<leader>rl` → `math/powm`.

## Usage

```cpp
powMod(2, 10)                 // 1024 (default modulus 998244353)
powMod(b, e, 1000000007)      // any modulus 1 <= mod < 2^31, e >= 0, b of any sign/size
powMod(a, p - 2, p)           // inverse of a modulo a prime p (p does not divide a)
```

## Complexity

O(log e).

## Example

for each query a b c (1 <= a < p) print a^(b^c) mod 1e9+7 (Fermat: the exponent is taken mod p - 1),
then the modular inverse of a.

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

#include "math/powm.cpp"  // in a solution: <leader>rl -> math/powm

int main() {
    const ll P = 1000000007;
    int q;
    cin >> q;
    while (q--) {
        ll a, b, c;
        cin >> a >> b >> c;
        ll e = powMod(b, c, P - 1);  // a^(p-1) = 1 since p does not divide a
        cout << powMod(a, e, P) << ' ' << powMod(a, P - 2, P) << '\n';
    }
}
```

```

3 7 1
15 2 2
2 0 5
```
